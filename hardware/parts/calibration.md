# Calibration apparatus — weights, scale, hanger

> Known-force references for the spring calibration (week 6) and the
> disturbance/weight-drop test (week 11). BOM rows: slotted weight set
> ($18–22), luggage scale ($10–15).

## Verified spec sheet (Aug 2026)

| Item | Spec | Use |
|---|---|---|
| Slotted weight set | 1 kg total (9 × 100 g + hanger); add hooked weights to 1.5 kg for week 11 | Known torque τ = m·g·r on the hanger arm |
| Luggage scale | 50 kg, ±10–50 g | Verify masses; ±3 % τ_hat check; size the week-11 drop |
| String + eyelet | ~1 m thin line | Hang weights without pendulum swing |

## Use / Don't use

- **USE** — the spring can't be calibrated to ±2 % without an external
  torque reference.
- Watch the display unit (kg vs lb) when recording.

## Acceptance checks

1. Weigh every mass against the luggage scale; correct the hanger card.
2. Spring calibration fits the cubic curve within ±2 % (week 6 milestone).

## Risks & caveats

- Pendulum swing from the weight hanger corrupts the calibration — use the
  string/eyelet.
- The 1 kg set is borderline for the 1.5 kg week-11 drop — order the hooked
  add-on with Order B.
